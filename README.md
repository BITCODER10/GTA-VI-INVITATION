# GTA VI · PS5 Party Invite

Neon Vice City–style GitHub Pages invite with an **EMEA [code] USER** access gate.

**Password:** `3DSPACE` (case-insensitive)

## Edit party details

Open [`config.js`](config.js) and change:

- `dateLabel` / `startISO` / `timeLabel`
- `placeLabel`
- `host`
- `rsvpWhatsApp` — digits with country code (e.g. `9198xxxxxxxx`) to show a WhatsApp button
- `loadout` — checklist items

## Preview locally

Open `index.html` in a browser, or:

```bash
npx serve .
```

## Deploy on GitHub Pages

1. Create a repo and push this folder to `main`
2. **Settings → Pages → Build and deployment**
3. Source: **Deploy from a branch** → `main` / `/ (root)`
4. Share the Pages URL with friends — they need the password to enter
